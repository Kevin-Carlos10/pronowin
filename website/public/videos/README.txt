Déposez ici vos vraies vidéos pour qu'elles remplacent automatiquement les posters placeholders :

- hero-loop.mp4       -> vidéo de fond du hero (muette, en boucle, ex: capture d'écran de l'app qui défile)
- demo-loop.mp4       -> vidéo de démonstration de l'application (section "Démo")

Format recommandé : MP4 (H.264), muet, 10-20 secondes, boucle, poids < 5 Mo pour un chargement rapide.
Tant que ces fichiers ne sont pas présents, les images placeholder (public/images/hero-poster.svg et demo-poster.svg) s'affichent à la place.
